# No note or tag field on stems (beyond a single category)

Stems carry only their text and one optional `category`; we deliberately do not add a freeform note or a multi-tag field. A note attached to a stem is a place to intellectualize the prompt instead of writing to it — exactly the reflective editing the exercise is designed to suppress. Any richer classification, if ever wanted, is done by the user on the exported corpus, not in the app.
