# Security Policy

Six Endings is a local-only mobile app. There is no backend, no server, and no account system, and the app performs no network communication of any kind. All user data (writing, settings, history) lives in a single SQLite database on the user’s device.

## Scope

This policy covers the iOS and Android application in this repository. There are no services, cloud components, or infrastructure to report against.

## Supported versions

Security fixes land in the latest published release.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security report. Contact the developer through [nicolobrandizzi.com](https://nicolobrandizzi.com/), and include:

- a description of the issue and its impact;
- how to reproduce it;
- the app version and platform you tested.

Reports are handled privately, and a fix is released before any public disclosure.
